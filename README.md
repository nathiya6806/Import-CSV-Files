# Import CSV Files Using Pandas

## About the Project
This project demonstrates how to import and analyse CSV files using Python and Pandas.

## Dataset
- Dataset: Iris Dataset
- Source: UCI Machine Learning Repository
- Records: 150
- Columns: 5

## Libraries Used
- Pandas
- NumPy
- Matplotlib

## Tasks Completed
- Imported CSV files using Pandas.
- Displayed the first and last five rows.
- Checked dataset information.
- Generated statistical summaries.
- Checked missing values.
- Created two visualizations using Matplotlib.

## Findings
The Iris dataset contains three flower species with 50 records each. Data visualization helps understand the flower measurements.

## Conclusion
Learned CSV file importing, data exploration and visualization using Python.
